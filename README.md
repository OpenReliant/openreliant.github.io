# openreliant.github.io

The organisation's root page, <https://openreliant.github.io/>, which sends visitors on to
OpenReliant's website at <https://openreliant.github.io/openreliant/>. Any other path that isn't one
of the projects' sites goes to the same path on that website, so <https://openreliant.github.io/docs/>
opens the documentation.

The projects' own sites are published from their repositories, and stay where they are:
[`/openreliant/`](https://github.com/OpenReliant/openreliant) and
[`/openreliant-mods/`](https://github.com/OpenReliant/openreliant-mods).

Search engines read `robots.txt` only at the root of a host, so it lives here. It names the
sitemaps of both sites: the website's own pages, its docs and the mods' site.
